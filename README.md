# 食光 AI · 每日饮食推荐系统

基于 Flask 的 AI 每日饮食推荐系统。普通用户填写身高、体重、忌口与口味后，
生成一日三餐食谱；管理员可查看所有用户的推荐记录。

## 技术栈

- Python 3 + Flask
- users.json 保存账号，history.json 保存推荐记录

## 运行方式

```bash
pip install flask
python app.py
```

浏览器打开 http://127.0.0.1:5000
